# 4. Writing Tools and Productivity

## Checking and editing
- **Spelling and grammar**: Tools → Spelling and grammar.
- **Word count**: Tools → Word count (Ctrl+Shift+C / Cmd+Shift+C).
- **Find and replace**: Ctrl+H / Cmd+Shift+H, with regular expressions.
- **Dictionary and Explore**: look up words and research from the side panel.

## Voice typing
Tools → Voice typing (Chrome browser, microphone needed).

## Citations
**Tools → Citations** adds a side panel to create references in MLA, APA or Chicago
style and insert citations into the text.

## Templates and building blocks
- **Template gallery** provides resumes, reports and letters.
- **Insert → Building blocks** adds meeting notes, project plans and similar layouts.

## Add-ons and extensions
**Extensions → Add-ons** installs extra tools such as diagram makers or
equation editors. **Extensions → Apps Script** allows automation.

## Keyboard shortcuts
Press Ctrl+/ (Cmd+/ on Mac) to see all shortcuts.

## Good technical-writing practice
- Use headings consistently.
- Keep paragraphs short and lists parallel.
- Add captions and alt text to figures.
- Use named versions for milestones.
