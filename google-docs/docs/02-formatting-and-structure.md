# 2. Formatting and Document Structure

## Text formatting
| Action | Shortcut (Windows / Mac) |
|--------|--------------------------|
| Bold | Ctrl+B / Cmd+B |
| Italic | Ctrl+I / Cmd+I |
| Underline | Ctrl+U / Cmd+U |
| Copy formatting | Paint format button |
| Clear formatting | Ctrl+\ / Cmd+\ |

## Styles and headings
Use **Normal text**, **Title**, **Heading 1** to **Heading 6** from the styles
dropdown (Ctrl+Alt+1, 2, 3 on Windows or Cmd+Option+1, 2, 3 on Mac).
Headings give the document a structure, feed the outline, and are used by the
table of contents.

To change a style for the whole document: format a paragraph, then choose
**Format → Paragraph styles → Update 'Heading 1' to match**.

## Lists
Bulleted, numbered and checklists from the toolbar, nested with Tab.

## Table of contents
**Insert → Table of contents** (with page numbers or with blue links).
It updates with the refresh button.

## Page setup
**File → Page setup** controls orientation, paper size, margins and page color.
**Insert → Page numbers** and **Headers & footers** add repeated content.

## Tables, images and drawings
- **Insert → Table** for tables (right-click for rows, columns, merge cells).
- **Insert → Image** to upload, search or paste a link; add alt text.
- **Insert → Drawing** for simple diagrams.
- **Insert → Equation** for math expressions.
- **Insert → Footnote**, **Bookmark**, **Link** (Ctrl+K).

## Document outline
**View → Show document outline** shows a clickable outline built from headings.
