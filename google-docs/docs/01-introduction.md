# 1. Introduction to Google Docs

Google Docs is a free, browser-based word processor that is part of Google Workspace.
Documents are stored in Google Drive and can be edited by several people at once.

## Why use it for technical writing?
| Feature | Benefit |
|---------|---------|
| Real-time collaboration | Several authors edit the same document together |
| Automatic saving | No lost work |
| Version history | Every change is recorded and can be restored |
| Comments and suggestions | Structured review workflow |
| Access anywhere | Works in a browser on any device, also offline with setup |
| Export | Download as PDF, Word, plain text, HTML or EPUB |

## Getting started
1. Open docs.google.com and sign in with a Google account.
2. Click **Blank document** or choose a **template**.
3. Give the document a name at the top left.
4. Start typing; the document saves automatically.

## Interface
- **Menu bar**: File, Edit, View, Insert, Format, Tools, Extensions, Help.
- **Toolbar**: font, size, styles, lists, alignment, spacing.
- **Ruler and margins**: control indents and page layout.
- **Share** button (top right) and **comment** and **version history** icons.

## Docs vs LaTeX
| | Google Docs | LaTeX |
|--|-------------|-------|
| Style | What you see is what you get | Markup compiled to PDF |
| Best for | Quick collaboration, simple reports | Math-heavy and long documents |
| Version control | Built-in history | Use Git |
