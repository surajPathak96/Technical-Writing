# 3. Sharing and Collaboration

## Sharing
Click **Share** and choose who can access the document.

| Setting | Meaning |
|---------|---------|
| Restricted | Only people you add by email |
| Anyone with the link | Anyone who has the URL |

Roles for each person:
| Role | Can do |
|------|--------|
| Viewer | Read only |
| Commenter | Read and comment |
| Editor | Edit and change sharing |

## Comments
Select text, then click the comment icon (Ctrl+Alt+M / Cmd+Option+M).
- Mention people with `@name` to notify them.
- Assign a comment as an action item.
- **Resolve** a comment when it is handled.

## Suggesting mode
Switch from **Editing** to **Suggesting** (the pencil icon, top right). Edits appear
as suggestions that the owner can **accept** or **reject**. This is similar to
tracked changes in Word.

## Real-time editing
Collaborators' cursors appear in different colors with their names. The built-in
chat and comments help coordinate.

## Version history
**File → Version history → See version history** lists every saved version.
- Name important versions (for example "Submitted draft").
- Restore an older version if needed.
- See who changed what, shown in each person's color.

## Offline and download
**File → Download** exports to PDF, Word (.docx), OpenDocument, RTF, plain text,
HTML or EPUB. **File → Make a copy** duplicates the document.
